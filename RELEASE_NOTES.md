# Starboard 12.7.2

A fix for the screen reader.

## Fixed

- **Screen reader error:** in 12.7.1, starting the screen reader for scan signatures showed "Method invocation failed because [System.Object[]] does not contain a method named 'op_Multiply'" and read nothing. It works again, with all the reading improvements from 12.7.1.

## Install or update

1. Download **StarboardSetup-12.7.2.exe** below and run it. It updates your current Starboard in place, and your ships, ledger, plans and settings stay as they are.
2. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. Starboard is not code-signed, so Windows warns until enough people have run it.
