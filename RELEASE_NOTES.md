# Starboard 12.7.1

A small fix release.

## Fixed

- **F9 typing mixed-up letters:** if two copies of Starboard were open at once, both typed /showlocation together and the letters came out mixed. Now only one open copy handles F8, F9 and F10. A second copy says so in SETTINGS and takes over when the first one closes.

- **Reading scan signatures from the screen:** more accurate. Starboard now reads each picture twice (as is, and a cleaned-up high-contrast copy you never see), fixes look-alike letters inside numbers (O to 0, I to 1, S to 5, B to 8), accepts a comma read as a period or a space, and only takes a number once two reads in a row agree. Small areas are enlarged more before reading.

## Install or update

1. Download **StarboardSetup-12.7.1.exe** below and run it. It updates your current Starboard in place, and your ships, ledger, plans and settings stay as they are.
2. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. Starboard is not code-signed, so Windows warns until enough people have run it.
